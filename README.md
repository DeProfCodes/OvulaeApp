# 🌸 Ovulae App — All-in-One Women's Health Tracker

**Ovulae** is a beautifully designed, cross-platform mobile app built using **.NET MAUI (C#)**, empowering women to take control of their reproductive health. From menstrual tracking to pregnancy milestones, Ovulae offers personalized support and insights through every stage of womanhood.

---

## 🚀 Features

### 🩸 Menstrual Cycle Tracker
- Predict upcoming periods and cycle patterns
- Log flow, mood, symptoms, and more
- Cycle insights tailored to your body

### 🟣 Ovulation & Fertility Tracker
- Identify fertile windows and ovulation days
- Track cervical mucus & body temperature (optional)
- Log intercourse and receive conception tips

### 🤰 Pregnancy Tracker
- Week-by-week fetal growth & development
- Diet and exercise suggestions per trimester
- Log symptoms, emotions, and health stats
- Pregnancy-safe sexual health guidance

### 🛡️ Privacy-First Onboarding
- Transparent health data usage
- Compliant with Google Play & App Store policies

## 🛠️ Tech Stack

| Technology   | Usage                                      |
|--------------|--------------------------------------------|
| .NET MAUI    | Cross-platform app framework (iOS/Android) |
| C#           | Backend logic and data modeling            |
| SQLite       | Local storage for user health logs         |
| MSSQL        | Cloud storage                              |
| Paystack API | Subscription billing and payments          |
| Firebase     | Notifications & optional backups           |
| Figma        | UI/UX Design Prototypes                    |

## 🔒 Privacy & Data Use
